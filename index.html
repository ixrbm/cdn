Catatan penggunaan

  • 1Pakai versi di nama file, misalnya style.v2.css, agar perubahan langsung terlihat tanpa menunggu cache.
  • 2File baru butuh 1–2 menit sebelum bisa dibuka lewat CDN, karena GitHub Pages memprosesnya dulu.
  • 3Hanya branch main yang tersaji. File di branch lain atau repo lain tidak punya link CDN.
  • 4File .css berisi CSS saja, tanpa tag <style>. Begitu juga file .js tanpa tag <script>.
  • 5Jangan simpan data rahasia di sini, karena semua file bersifat publik.
